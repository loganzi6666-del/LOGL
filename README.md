# LOGL

실제 국경과 실제 국력으로 시작하는 AI 지정학 시뮬레이션.

당신은 한 나라를 맡아 한국어로 지시를 내립니다. 전쟁으로 얻은 땅은 지도에 그대로 반영됩니다.

**결제 없이 그냥 됩니다.** 내장 한국어 명령 해석기가 "북한에 선전포고하고 개성으로 전 병력을
투입하라" 같은 지시를 즉시 알아듣습니다. API 키는 각 나라가 LLM으로 스스로 판단하게 만들고
싶을 때만 필요하고, 그마저도 무료로 쓰는 방법이 있습니다.

```
┌─ 1,641개 주 · 197개 국가 ─────────────────────────────────────┐
│  국경: Natural Earth 1:50m                                    │
│  주:   GeoNames 실제 행정구역(admin-1) 기준으로 분할            │
│  인구: 실제 도시 인구를 쌓아 올림                               │
│  국력: 실제 GDP · 국방비 · 병력 · 핵탄두                        │
└───────────────────────────────────────────────────────────────┘
```

---

## 핵심 설계: AI는 '의도'를, 엔진은 '결과'를 정합니다

이런 게임에서 가장 흔한 실패는 LLM에게 전투 결과까지 맡기는 것입니다. 그러면 AI가
"우리 군이 서울을 함락했습니다"라고 그럴듯하게 지어내고, 지도와 이야기가 따로 놀기
시작합니다.

LOGL은 역할을 나눕니다.

| | 담당 | 하는 일 |
|---|---|---|
| **LLM** | 판단 | 플레이어 지시 해석, 각국의 의사결정, 정세 보고문 작성 |
| **엔진** | 결과 | 전투 판정, 보급, 경제, 영토 이전, 강화 수락 여부 |

LLM이 내놓은 모든 명령은 엔진의 검증기를 통과해야 합니다. 인접하지 않은 지역으로
진격하거나, 없는 돈을 쓰거나, 점령하지도 않은 땅의 할양을 요구하면 **거부 사유와 함께
반려됩니다.** 모델이 아무리 확신에 차서 말해도 국경은 움직이지 않습니다.

주사위는 시드 기반이라, 같은 저장 파일에 같은 명령을 주면 항상 같은 전쟁이 벌어집니다.

## 설치 — 컴퓨터를 잘 모르셔도 됩니다

필요한 건 **딱 두 가지**입니다. Node.js(프로그램을 돌려주는 도구)와 이 코드.

### 1단계 · Node.js 설치 (한 번만)

[nodejs.org](https://nodejs.org) 에 들어가 **LTS**라고 적힌 큰 버튼을 눌러 받고,
받은 파일을 실행해 "다음 → 다음 → 설치"만 누르면 끝입니다. 설정은 건드리지 마세요.

### 2단계 · 코드 내려받기

GitHub 저장소 페이지에서 초록색 **`< > Code`** 버튼 → **Download ZIP** 을 누릅니다.
받은 zip 파일을 압축 해제하면 `LOGL-...` 이라는 폴더가 생깁니다. 바탕화면처럼
찾기 쉬운 곳에 두세요.

### 3단계 · 터미널 열기

- **Windows**: 시작 메뉴에서 `PowerShell` 검색 → 실행
- **Mac**: `Command(⌘) + 스페이스` → `터미널` 입력 → 실행

검은(또는 흰) 창이 뜨면 성공입니다. 여기에 명령어를 한 줄씩 칩니다.

### 4단계 · 폴더로 이동

창에 `cd ` 를 치고 **한 칸 띄운 뒤**, 2단계에서 만든 폴더를 마우스로 끌어다
창 안에 놓으세요. 경로가 자동으로 입력됩니다. `Enter`.

```
cd C:\Users\내이름\Desktop\LOGL-claude-stoic-franklin-rvs66u
```

### 5단계 · 준비물 설치

```bash
npm install
```

`Enter` 를 누르고 1~2분 기다립니다. 글자가 쭉 올라가다 멈추면 완료입니다.
(노란 `warn` 글씨는 무시해도 됩니다. 빨간 `ERR!` 만 문제입니다.)

### 6단계 · 실행

```bash
npm start
```

처음 한 번은 세계 지도를 만드느라 20초쯤 걸립니다. 아래처럼 나오면 성공입니다.

```
  LOGL — AI 지정학 시뮬레이션
  http://localhost:5173
```

브라우저 주소창에 **`localhost:5173`** 을 치면 게임이 뜹니다.

> **여기서 끝입니다.** 한국어 명령 입력도, 세계 각국의 움직임도 전부 동작합니다.
> 설정할 것도, 낼 돈도 없습니다.

터미널 창을 닫으면 게임 서버도 꺼집니다. 다시 하려면 4~6단계(폴더 이동 → `npm start`)를
반복하면 됩니다. 종료는 터미널에서 `Ctrl + C`.

### 7단계 · 더 똑똑한 AI (선택, 안 해도 됩니다)

기본 상태에서도 각국은 국력·동맹·상대의 취약함을 따져 움직입니다. 여기에 LLM을 붙이면
각 나라가 자기 독트린을 읽고 스스로 판단하며, 매달 정세 보고문도 써 줍니다.

**방법 A · 내 컴퓨터에서 돌리기 (무료)**

[ollama.com](https://ollama.com) 에서 Ollama를 설치한 뒤 터미널에:

```bash
ollama pull qwen2.5:7b
```

`.env` 파일을 만들고(`copy .env.example .env` / `cp .env.example .env`) 아래 세 줄의
`#` 을 지웁니다.

```bash
LLM_PROVIDER=openai
OPENAI_BASE_URL=http://localhost:11434/v1
OPENAI_MODEL=qwen2.5:7b
```

요금은 들지 않지만 컴퓨터가 좀 버거워할 수 있습니다. 느리면 `.env` 의
`AI_THINKING_NATIONS` 를 `3` 정도로 낮추세요.

**방법 B · Claude 또는 ChatGPT (유료)**

`.env` 에 키를 넣습니다. 가장 매끄럽지만 턴마다 요금이 붙습니다.

```bash
LLM_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_MODEL=claude-haiku-4-5    # 저렴한 쪽
```

어느 쪽이든 `Ctrl + C` 로 서버를 끄고 `npm start` 로 다시 켜야 적용됩니다.

### 잘 안 될 때

| 증상 | 해결 |
|---|---|
| `npm : 용어를 인식할 수 없습니다` / `command not found: npm` | Node.js 설치가 안 됐거나 터미널을 껐다 켜야 합니다. 터미널을 닫고 다시 여세요. |
| `Cannot find module` | 5단계 `npm install` 을 건너뛰었습니다. 폴더 안에서 다시 실행하세요. |
| `EADDRINUSE` (포트 사용 중) | 이미 켜져 있습니다. 브라우저에서 `localhost:5173` 을 열어보세요. |
| 페이지가 하얗게만 나옴 | 터미널에 빨간 글씨가 있는지 확인하고, `Ctrl + C` 후 `npm start` 를 다시 하세요. |
| 지도가 안 보임 | 첫 실행은 지도 생성에 20초쯤 걸립니다. 터미널에 `http://localhost:5173` 이 뜬 뒤에 여세요. |

### 요약 (익숙해진 뒤)

```bash
npm install
npm start     # → http://localhost:5173   (.env 없이도 완전히 동작합니다)
```

## 플레이 방법

1. **국가를 고릅니다.** 197개국 전부 플레이할 수 있습니다. 룩셈부르크로 시작해도 됩니다.
2. **지시를 입력합니다.** 아래쪽 입력창에 평소 말하듯 씁니다.
3. **[해석]** 을 누르면 지시가 명령으로 바뀌고, 무엇이 왜 불가능한지 알려줍니다.
   실행 전에 확인하고 취소할 수 있습니다.
4. **[턴 종료]** 로 한 달이 흐릅니다. 각국 AI가 움직이고, 전투가 판정되고, 지도가 갱신됩니다.

지도를 클릭하면 그 지역에서 가능한 행동(진격·이동·요새화·선전포고)이 버튼으로도 뜹니다.
지역을 클릭해 두고 그냥 "공격하라"라고만 쳐도 됩니다.

### 무료 해석기가 알아듣는 말

| 이렇게 쓰면 | 이렇게 됩니다 |
|---|---|
| `북한에 선전포고` | 선전포고 |
| `개성 공격` / `평양으로 진격` / `전 병력 투입` | 우리 병력이 가장 많은 인접 지역에서 공세 |
| `북한을 공격` (지역 안 쓰고) | 공격 가능한 적 지역 중 유리한 곳을 골라 공세 |
| `제주로 상륙` | 1,200km 안의 해안에서 상륙작전 |
| `서울로 집결` / `부산으로 이동` | 전 병력이 그쪽으로 한 칸씩 이동 |
| `5개 사단 증강` | 신규 편성 (예산·인력 한도 내에서) |
| `경제에 20 투자` / `기술 연구에 투자` | 투자 |
| `국방비를 4%로` | GDP 대비 국방예산 조정 |
| `서울 요새화` | 요새 강화 |
| `북한과 강화` | 점령 중인 지역을 요구하는 강화 제안 (없으면 백지 강화) |
| `일본과 동맹` / `일본과 관계 개선` / `러시아 제재` | 외교 |
| `북한 군사력 어때?` / `개성 상황 알려줘` | 답변만 하고 **턴은 넘어가지 않습니다** |

지명은 한국·북한·일본·중국·대만 전역과 세계 각국 수도를 한국어로 알아듣습니다
(`서울` `평양` `개성` `도쿄` `베이징` `모스크바` …). 못 알아듣는 지명은 지도에 뜨는
영문 이름을 그대로 치거나, 지도에서 클릭한 뒤 지시하면 됩니다.
빠진 지명은 `data/place-names-ko.json` 에 한 줄 추가하고 `npm run build:world` 하면
바로 인식합니다.

### 지도 읽는 법

| 표시 | 뜻 |
|---|---|
| 검정(밝은 테마) / 흰색(어두운 테마) | 우리 영토 |
| 단색 | 그 나라의 영토. 인접국끼리는 반드시 다른 색 |
| 빗금 | **점령지** — 통제하고 있지만 영유권은 아직 상대에게 있음 |
| 빨간 점선 | 교전 중인 전선 (굵을수록 전선이 밀린 상태) |
| 노란 테두리 | 이번 턴에 영유권이 넘어간 곳 |
| 원 안의 숫자 | 사단 수 |

### 땅을 얻는 법 — 두 단계입니다

점령과 영유권은 다릅니다. 이게 이 게임의 핵심 규칙입니다.

1. **점령**: 공세를 계속하면 전선이 밀립니다. 전선이 100%에 닿으면 그 주의 *통제권*을
   가져옵니다. 지도에는 빗금으로 표시됩니다.
2. **영유권**: 강화 조약을 맺어야 *영유권*이 넘어옵니다. 이때 비로소 지도가 그 나라
   색으로 완전히 칠해집니다.

상대는 전쟁점수(실제로 점령한 땅의 가치)와 국내 사정(전쟁 피로·전쟁 지지·안정도)을
따져 수락 여부를 정합니다. **점령하지 않은 땅은 요구할 수 없습니다.** 말로 얻어낼 수
있는 건 없습니다.

## 명령 목록

자연어로 쓰면 참모본부가 알아서 아래 명령으로 바꿔 줍니다. 직접 지정해도 됩니다.

| 명령 | 설명 |
|---|---|
| `OFFENSIVE` | 인접한 적 통제 지역으로 지상 공세 |
| `NAVAL_INVASION` | 해안에서 1,200km 이내 적 해안으로 상륙 |
| `MOVE` | 아군 지역 사이 병력 이동 |
| `RECRUIT` | 신규 사단 편성 (예산·인력·동원속도 제약) |
| `FORTIFY` | 요새 수준 강화 (최대 5) |
| `INVEST` | 경제 또는 군사기술에 투자 |
| `SET_DEFENCE_SHARE` | GDP 대비 국방예산 조정 (급격히 올리면 안정도 하락) |
| `DECLARE_WAR` | 선전포고 (정전 협정 중에는 불가) |
| `PROPOSE_PEACE` | 강화 제안 — 할양 요구는 점령 중인 지역만 |
| `FORM_ALLIANCE` / `BREAK_ALLIANCE` | 동맹 체결 / 파기 |
| `IMPROVE_RELATIONS` / `SANCTION` / `MILITARY_AID` | 관계 개선 / 제재 / 군사원조 |
| `NUCLEAR_STRIKE` | 핵 사용. 되돌릴 수 없고, 전 세계가 등을 돌리며, 보복을 부릅니다 |
| `STATEMENT` | 기계적 효과 없는 성명. 다른 나라 AI가 읽습니다 |

## AI가 각국을 연기하는 방식

**API 키가 없으면** 모든 나라가 규칙 기반 AI로 움직입니다. 한 턴이 0.3초 안에 끝나고
요금이 없습니다. 아래는 키를 붙였을 때의 이야기입니다.

매 턴, 플레이어와 관련이 깊은 나라부터 순서대로 LLM이 직접 사고합니다.
교전국 → 접경국 → 동맹국 → 경쟁국 → 강대국 순입니다. 기본 10개국이며
`.env`의 `AI_THINKING_NATIONS`로 조절합니다.

나머지 약 190개국은 규칙 기반 AI로 움직입니다. 이쪽도 국지적 전력 균형, 상대 동맹국의
개입 가능성, 대상국의 불안정도를 따져 판단합니다. 그래서 아무도 손대지 않아도
인도–파키스탄, 세르비아–코소보, 콩고–르완다, 이스라엘–시리아, 러시아–조지아 같은
실제 분쟁 지점에서 전쟁이 터집니다.

각 나라의 행동 원리는 `data/nations-seed.json`의 `doc`(독트린) 필드에 적혀 있습니다.

```json
"KR": { "doc": "북한의 핵·재래식 위협 억제가 절대적 우선순위. 한미동맹과 확장억제에 …" }
```

**이 글을 고치면 그 나라가 다르게 행동합니다.** 일본을 팽창주의로 바꾸거나, 스위스를
개입주의로 만들어 보세요. 고친 뒤에는 `npm run build:world`로 다시 생성합니다.

### 비용

한 턴에 LLM 호출은 `AI_THINKING_NATIONS + 2`회입니다(각국 사고 + 지시 해석 + 정세 보고).
국가별 사고는 `effort: low`에 시스템 프롬프트를 캐싱해 호출당 비용이 작습니다.
비용을 더 줄이려면 `AI_THINKING_NATIONS`를 낮추거나 더 작은 모델을 쓰세요.

## 수치가 어디서 왔는지

| 항목 | 출처 |
|---|---|
| 국경 | Natural Earth 1:50m (`world-atlas`) |
| 주 경계 | GeoNames 실제 admin-1 행정구역을 시드로 한 보로노이 분할 후 실제 국경으로 절단 |
| 주 이름 | 그 주에서 가장 큰 실제 도시 |
| 인구 | 실제 도시 인구 + 나머지를 면적 비례 분배 (합계는 실제 국가 인구와 일치) |
| GDP · 국방비 · 병력 · 핵탄두 | World Bank / IMF / SIPRI / IISS / FAS 공개 자료 기준 근사치 (2024년 전후) |

게임 수치는 가능한 한 이 자료에서 **유도**합니다. 예를 들어 사단 1개의 유지비는 그
나라의 실제 국방예산을 실제 병력으로 나눈 값입니다. 그래서 미군 1개 사단이 북한군
1개 사단의 220배 비용이 들고, 대신 북한은 4배 많은 사단을 굴립니다. 장비 품질도
병사 1인당 국방비에서 나옵니다.

인접 관계는 ISO 공식 국경 데이터와 대조해 643건 중 634건이 일치합니다
(불일치는 세우타·멜리야 같은 월경지와 해상 경계입니다).

⚠️ 모든 수치는 게임용 근사치입니다. 현실의 통계로 인용하지 마세요.

---

## 구조

```
scripts/build-world.mjs   지도 생성 (국경 + 행정구역 + 도시 → data/world.json)
scripts/build-client.mjs  브라우저 번들 (esbuild)
scripts/smoke.mjs         실제 브라우저로 게임을 플레이해 보는 검증

src/game/                 결정론적 시뮬레이션 — 여기서만 국경이 움직입니다
  rules.js                실제 데이터에서 게임 수치를 유도하는 공식
  military.js             보급·참호·전투 판정
  diplomacy.js            전쟁점수·강화·동맹
  economy.js              예산·징병·안정도
  orders.js               명령 어휘와 검증기 ← LLM과 엔진의 계약
  engine.js               한 달을 해석하는 순서

src/ai/                   LLM 계층 — 의도만 정합니다
  context.js              각국이 읽는 상황 브리핑
  arbiter.js              플레이어 자연어 → 명령
  nation.js               국가별 AI + 사고 예산 배분
  heuristic.js            나머지 190개국의 규칙 기반 AI
  narrator.js             정세 보고문

src/llm/                  Claude / ChatGPT 공통 인터페이스
public/                   지도와 UI
```

---

## 개발

```bash
npm run dev          # 서버 + 번들 감시
npm test             # 18개 테스트 (네트워크 불필요)
npm run build:world  # 지도 재생성 — nations-seed.json을 고친 뒤 실행
node scripts/smoke.mjs   # 실제 브라우저로 검증 + 스크린샷 (npm start 후)
```

테스트는 전쟁이 선포되고, 땅이 점령되고, 강화로 영유권이 넘어가는 전 과정과,
같은 시드가 같은 세계를 만드는지, 그리고 LLM이 만들어낸 불법 명령이 전부 걸러지는지를
확인합니다. API 키 없이 전부 돌아갑니다.
